# Infant MSC Lipid Metabolism and Childhood Adiposity

Supplementary data accompanying the manuscript:

"Lipid Metabolism in Neonatal Mesenchymal Stem Cells
Associates with Childhood Adiposity"

American Journal of Physiology – Endocrinology & Metabolism

## Supplementary Data

Supplementary_Data.xlsx contains the supplementary tables
supporting the manuscript, organized into separate worksheets.

These include participant characteristics, additional analyses,
and transcriptomic results.

## Data Availability

The supplementary results are provided in the accompanying
Excel workbook. Individual participant-level data are not included.
